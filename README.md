
# Retail Order Routing System

This project simulates an omni-channel retail backend for handling product fulfillment logic: Buy Online Pick Up In Store (BOPIS), Same Day Delivery, and Ship-to-Store.

## Features

- Inventory check by store and product
- Fulfillment logic based on distance and availability
- Simulated order routing system
- Data stored in MySQL-compatible schema
- Future deployment with AWS Lambda or EC2

## Technologies

- Python (Flask or FastAPI)
- MySQL
- AWS (Lambda, RDS)
- Tableau or Streamlit for dashboard
- Optional: Geopy for distance calculations
